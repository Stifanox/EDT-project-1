## Notatki z realizacji
- Pakiet nazywa się `opimon` (ang. *opinion monitor*). Python ≥ 3.11 (venv: 3.13).
- Model danych binarny (pozytywny / negatywny), zgodnie z wytycznymi. `score` = P(pozytywny),
  dzięki temu progi i średnie są porównywalne między modelami.
- Etykieta ze źródła (`Review.label`, np. Steam `voted_up`) jest oddzielona od predykcji:
  pozwala oceniać modele na danych z Internetu (M5), co jest mocnym punktem projektu.
- Predykcje są przechowywane per (opinia, model), więc dashboard może przełączać modele bez przeliczania.
- Domyślny model = pierwszy GOTOWY w `_make_models()`; O2 steruje kolejnością.
- `SampleSource` jest offline. Wymaganie „dane do predykcji z Internetu” spełniają D1 (API) i D3 (scraping).
- Daty w `reviews.jsonl` są względne (`age_hours`), więc demo zawsze pokazuje ostatnie 30 dni.
- Usunięto szablonowy `main.py` z PyCharm.
- Wynik: 79 testów zielonych (1 pominięty celowo: test treningu dla modelu bez treningu), `ruff check .` czyste, `streamlit run app.py` startuje.
