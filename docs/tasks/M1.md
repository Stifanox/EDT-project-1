# M1 – Zbiór treningowy IMDB

**Właściciel:** O2 · **Zależności:** !P0 · **Status:** patrz [`PROGRESS.md`](../../PROGRESS.md)

## Cel
Prawdziwe dane treningowe: 50 tys. recenzji filmowych IMDB (Kaggle / Hugging Face), czyszczone tak samo jak dane z Internetu.

## Zakres
- `ImdbTrainingData` (`name="imdb"`) implementujący `TrainingDataProvider`.
- Plik z Kaggle (`IMDB Dataset.csv`) w `config.DATASETS_DIR` albo pobranie z Hugging Face.
- Analiza zgodności z danymi do predykcji (długość, słownictwo).

## Pliki (własność)
- `opimon/sentiment/imdb.py` – nowy
- `opimon/sentiment/__init__.py` – edycja
- `opimon/services.py` -> `_make_training_data()` – edycja
- `tests/contracts/test_training_data_contract.py` -> `PROVIDER_FACTORIES` – edycja
- `tests/fixtures/imdb_mini.csv`, `tests/test_imdb.py` – nowe
- `scripts/download_imdb.py` – nowy (opcjonalnie)

## Kontrakt / API
Udostępnia `TrainingDataProvider`. Zbiory w `config.DATASETS_DIR`, cache w `config.CACHE_DIR`.

## Kryteria akceptacji
- [ ] `ImdbTrainingData` czyta `IMDB Dataset.csv` (Kaggle) lub zbiór z Hugging Face; brak danych -> `DatasetUnavailableError` z instrukcją pobrania
- [ ] Czyszczenie `textproc.clean_text` (IMDB zawiera `<br />`), tak samo jak dane z Internetu
- [ ] Deterministyczny, zbalansowany podział train/test; działają `max_train` i `max_test`
- [ ] Cache przetworzonego zbioru w `config.CACHE_DIR`; drugie wczytanie < 2 s
- [ ] Przechodzi test kontraktowy na pliku-fixture `tests/fixtures/imdb_mini.csv`
- [ ] IMDB pierwszy w `_make_training_data()`; w notatkach statystyki zbioru i porównanie z danymi Steam / IMDb (uzasadnienie spójności)

## Wskazówki
- Kaggle: *IMDB Dataset of 50K Movie Reviews* (kolumny `review`, `sentiment`). Hugging Face: `stanfordnlp/imdb` (można pobrać parquet bez biblioteki `datasets`).
- Komunikat `DatasetUnavailableError` ma podać dokładną ścieżkę, pod którą trzeba położyć plik.
