# A4 – Słowa kluczowe: co chwalą, a co krytykują

**Właściciel:** O3 · **Zależności:** !P0 · **Status:** patrz [`PROGRESS.md`](../../PROGRESS.md)

## Cel
Wyjaśnić sentyment: słowa i frazy charakterystyczne dla opinii pozytywnych i negatywnych oraz to, co zmieniło się ostatnio.

## Zakres
- `top_terms` z wagą (log-odds / lift), bigramy, porównanie okresów.

## Pliki (własność)
- `opimon/analytics/terms.py` – nowy
- `opimon/analytics/core.py` – edycja (A1)
- `tests/test_terms.py` – nowy
- `pages/4_Dashboard.py` – edycja (sekcja słów)

## Kontrakt / API
`top_terms` (kontrakt) + `emerging_terms(rows, recent_days, now) -> list[TermStat]`.

## Kryteria akceptacji
- [ ] `top_terms` ważone log-odds (lub lift) pozytywne vs negatywne, z bigramami („frame rate”, „waste money”)
- [ ] Minimalna liczba wystąpień: rzadkie słowa nie dominują przy małych próbkach
- [ ] `emerging_terms`: słowa częstsze w ostatnim okresie niż wcześniej (na danych demo: „patch”, „update”)
- [ ] Wizualizacja na dashboardzie; kliknięcie słowa -> `nav.open_reviews(term=…)`
- [ ] Testy

## Wskazówki
- Używaj `textproc.content_tokens`; jeśli potrzebujesz bigramów, dodaj nową funkcję w `textproc` (zmiana wstecznie zgodna, wpis w dzienniku) albo zaimplementuj je lokalnie.

## Poza zakresem
