## Cel
Pierwsze prawdziwe źródło danych do predykcji: recenzje gier z publicznego API Steam (bez klucza). Spełnia wymaganie „dane do predykcji pochodzą z Internetu (API)”.

## Zakres
- `SteamReviewSource` (`name="steam"`) implementujący `ReviewSource`.
- Wyszukiwanie gier po nazwie (store search API).
- Pobieranie recenzji z paginacją kursorem, przyrostowo (`since`).
- Mapowanie pól Steam na `Review` (etykieta `voted_up`, metadane w `extra`).
- Testy offline na nagranych odpowiedziach JSON + wariant `network`.

## Wskazówki
- Recenzje: `GET https://store.steampowered.com/appreviews/{appid}?json=1&filter=recent&language=english&num_per_page=100&purchase_type=all&cursor=*`. Kolejny kursor jest w odpowiedzi; przekaż go zakodowany URL-em. `filter=recent` sortuje od najnowszych, co ułatwia obsługę `since`.
- Wyszukiwanie: `GET https://store.steampowered.com/api/storesearch/?term=<q>&l=english&cc=US`.
- Nieznany appid zwraca zwykle `success: 1` z pustą listą i `total_reviews: 0`. Rozróżnij to od „gra bez recenzji” przez `query_summary`, a decyzję zapisz w notatkach.
- Transport HTTP wstrzykuj w konstruktorze (np. `session=` / `get_json=`), żeby test podmienił go na fixture.
- Język: wymagamy `english`, bo modele są anglojęzyczne. Ustaw `Review.language="en"`.
