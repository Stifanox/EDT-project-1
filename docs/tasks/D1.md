# D1 – Źródło Steam Reviews API

**Właściciel:** O1 · **Zależności:** !P0 · **Status:** patrz [`PROGRESS.md`](../../PROGRESS.md)

## Cel
Pierwsze prawdziwe źródło danych do predykcji: recenzje gier z publicznego API Steam (bez klucza, `IUserReviewsService/GetAppReviews`). Spełnia wymaganie „dane do predykcji pochodzą z Internetu (API)”.

## Zakres
- `SteamReviewSource` (`name="steam"`) implementujący `ReviewSource`.
- Wyszukiwanie gier po nazwie (store search API).
- Pobieranie recenzji z paginacją kursorem, przyrostowo (`since`).
- Mapowanie pól Steam na `Review` (etykieta `voted_up`, metadane w `extra`).
- Testy offline na nagranych odpowiedziach JSON + wariant `network`.

## Wskazówki
- Recenzje: `GET https://api.steampowered.com/IUserReviewsService/GetAppReviews/v1/?input_json={...}`
  (dokumentacja: https://partner.steamgames.com/doc/webapi/IUserReviewsService). Stary endpoint
  `store.steampowered.com/appreviews/<appid>?json=1` Valve wyłączył 22.10.2026; przekierowuje na stronę główną.
- Parametry jako enumy: `filter=1` (Recent, od najnowszych), `purchase_type=1` (All), `languages=["english"]`;
  stringi („recent”) są po cichu ignorowane. Odpowiedź w `{"response": {...}}`, bez pola `success`.
- Wyszukiwanie: `GET https://store.steampowered.com/api/storesearch/?term=<q>&l=english&cc=US`.
- Transport HTTP wstrzykiwany w konstruktorze (`http=`), żeby test podmienił go na fixture.
- Język: wymagamy `english`, bo modele są anglojęzyczne. Ustaw `Review.language="en"`.

## Notatki z realizacji
**Zrobione 2026-11-04, 7/7.**

**Zmiana API Steam.** Pierwsza wersja korzystała z `store.steampowered.com/appreviews/<appid>?json=1`,
który Valve wyłączył 22.10.2026 (adres przekierowuje na stronę główną sklepu, także w przeglądarce).
Źródło używa oficjalnego następcy `IUserReviewsService/GetAppReviews/v1` (bez klucza, parametry w
`input_json`, enumy zamiast stringów, odpowiedź w `response`, brak pola `success`, nieznany appid
-> `{"response": {}}`). Zweryfikowane na żywo: `pytest -m network` 6/6, pobranie 200 recenzji
Cyberpunk 2077 przez fasadę w ok. 3 s, drugie pobranie przyrostowe = 0 nowych.

Decyzje:
- `opimon/sources/http.py` – `HttpClient` wspólny dla źródeł O1 (D3 użyje go ponownie):
  `allow_redirects=False` (3xx z API = błąd, a nie strona HTML udająca dane; dzięki temu wycofanie
  starego endpointu dało czytelny komunikat), 429 / 5xx / timeout / brak połączenia / zły JSON ->
  `SourceError` po polsku; odstęp `config.REQUEST_DELAY_S` czytany w chwili zapytania; zegar i
  `sleep` wstrzykiwane (testy bez czekania).
- Transport wstrzykiwany w konstruktorze (`SteamReviewSource(http=...)`); testy offline używają
  `tests/fixtures/steam/fake.py` (`FakeSteamHttp`, `make_offline_steam_source`).
- Fixtures: prawdziwe nagrane odpowiedzi to `search_dota.json`, `appdetails_*.json`,
  `live_570_page{1,2}.json` i `reviews_unknown.json`. Ręcznie przygotowane w formacie API są
  `reviews_570_page{1,2,3}.json`, z przypadkami brzegowymi: BBCode, encje, URL, pusta recenzja,
  duplikat między stronami, koniec paginacji powtórzonym kursorem.
- `filter_offtopic_activity=false`: Steam domyślnie ukrywa recenzje z „review bombów”, a dla
  monitoringu sentymentu to istotny sygnał (np. dla alertów A5).
- Paginacja kończy się, gdy: osiągnięto `limit`, strona jest pusta, kursor się powtórzył, pojawiła się
  opinia `created_at <= since` (`filter=1` sortuje od najnowszych) albo po `MAX_PAGES = 200` stronach.
- Nieznany appid: pierwsza strona bez recenzji -> zapytanie `appdetails`; `success: false` ->
  `SourceError`, w przeciwnym razie gra istnieje, tylko nie ma recenzji po angielsku -> `[]`.
- Uszkodzone pozycje (bez `recommendationid` / `review` / `timestamp_created` / `voted_up`) są
  pomijane z ostrzeżeniem w logu; strona złożona wyłącznie z takich pozycji -> `SourceError`.
- `extra`: `playtime_hours`, `playtime_at_review_hours` (minuty -> godziny), `votes_up`, `votes_funny`,
  `weighted_vote_score`, `steam_purchase`, `received_for_free`, `early_access`, `refunded`.
  `url` = strona recenzji na steamcommunity.com.
- Dodatkowa metoda poza Protocol: `target_from_appid(appid)` do ręcznego dodawania gry w D4.
- `steam` jest pierwszym źródłem w `_make_sources()`, `sample` zostaje jako tryb offline. Wspólny
  test `test_ui_smoke.py::test_fetch_flow_on_sources_page` wybiera teraz jawnie źródło `sample`,
  żeby test nie korzystał z sieci (intencja testu bez zmian).
- Ograniczenia: bez klucza obowiązuje wspólny, niższy limit zapytań (HTTP 429 -> komunikat),
  a odpowiedzi mogą być cache'owane przez Steam do 10 minut, więc najnowsze recenzje pojawiają się
  z opóźnieniem.
- Testy: `tests/test_source_steam.py` (offline + 1 `network`), kontrakt `steam-offline` i `steam-live`
  (`network`). `pytest -m "not slow and not network"` = 112 zielonych, `ruff` czyste.
