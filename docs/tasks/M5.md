# M5 – Ewaluacja i porównanie modeli (ta sama vs inna domena)

**Właściciel:** O2 · **Zależności:** !M1, ~M2, ~M3, ~M4, ~D1 · **Status:** patrz [`PROGRESS.md`](../../PROGRESS.md)

## Cel
Odpowiedź na pytanie, który model najlepiej ocenia opinie z Internetu i ile tracimy na zmianie domeny (IMDB -> Steam / IMDb na żywo). To merytoryczny rdzeń „inteligencji” systemu.

## Zakres
- Rozszerzenie `opimon/sentiment/evaluation.py`: porównanie wielu modeli, przykłady błędów.
- Ewaluacja na opiniach z Internetu, które mają etykietę ze źródła.

## Pliki (własność)
- `opimon/sentiment/evaluation.py` – edycja
- `opimon/services.py` -> metody O2 (`evaluate_model`, nowe `compare_models`) – edycja
- `tests/test_evaluation.py` – nowy

## Kontrakt / API
`compare_models(models, examples, dataset_name) -> pd.DataFrame`, `disagreements(models, reviews) -> list[...]` dla M7 i A3.

## Kryteria akceptacji
- [x] `compare_models` zwraca tabelę: accuracy, precision, recall, F1, czas, n (liczby, nie stringi)
- [x] Porównanie: test IMDB vs opinie z Internetu z etykietą (Steam `voted_up`, ocena IMDb), osobno per źródło
- [x] Lista przykładów błędów i niezgodności modeli
- [x] Wyniki zapisywane (JSON w `config.CACHE_DIR` lub tabela), żeby widok nie przeliczał ich przy każdym odświeżeniu
- [x] Wnioski w notatkach: który model domyślny i dlaczego (materiał do X2)
- [x] Testy na danych przykładowych

## Wskazówki

## Notatki z realizacji
- 2026-11-08: wszystkie modele oceniono na identycznych 1000 recenzjach IMDB test
  (500/klasę, seed 13) oraz tej samej próbce Steam z M2/M4 (n=199, 165 pozytywnych).
  Model TF-IDF wytrenowano na 24 862 recenzjach IMDB, bez wykorzystania testu.

  | Model | Dane | n | Accuracy | Precision | Recall | F1 | Czas predykcji [s] |
  |-------|------|---|----------|-----------|--------|----|--------------------|
  | TF-IDF + LR | IMDB test | 1000 | 0,8900 | 0,8794 | 0,9040 | 0,8915 | 0,264 |
  | VADER | IMDB test | 1000 | 0,6870 | 0,6373 | 0,8680 | 0,7350 | 1,409 |
  | DistilBERT | IMDB test | 1000 | 0,8810 | 0,8912 | 0,8680 | 0,8794 | 199,733 |
  | TF-IDF + LR | Steam live | 199 | 0,7487 | 0,8808 | 0,8061 | 0,8418 | 0,008 |
  | VADER | Steam live | 199 | 0,7789 | 0,8758 | 0,8545 | 0,8650 | 0,014 |
  | DistilBERT | Steam live | 199 | 0,6935 | 0,9643 | 0,6545 | 0,7798 | 8,860 |

- Domyślny: TF-IDF + LR — najlepszy wynik IMDB, szybki trening i predykcja, trwałość
  i interpretowalne wkłady cech. VADER jest użytecznym fallbackiem bez treningu.
  Różnica accuracy test/live wynosi odpowiednio 14,13 / -9,19 / 18,75 p.p.; nie jest
  czystą miarą wpływu domeny: próbki różnią się długością i rozkładem etykiet.
  Reguła zawsze pozytywna uzyskuje na Steam 82,91%, więcej niż każdy oceniony model.
  Wysokie F1 klasy pozytywnej przy przewadze tej klasy nie dowodzi dobrej jakości ogólnej.
  Dalsze porównanie wymaga większej, reprezentatywnej próbki i kontroli etykiet.
- Próbka Steam obejmuje aplikacje 1091500 i 570, po 100 najnowszych angielskich
  recenzji z aktualnego publicznego API Valve, 1 pusty tekst odrzucony. Etykiety wyłącznie
  z `voted_up`, nigdy z predykcji. Opinie demo są oznaczone `demo:sample`.
  Fasada filtruje osobno każde źródło (także IMDb/rating po dostarczeniu D3 przez O1).
  Pomiar filmów IMDb live pozostaje elementem integracji z D3; nie podajemy fikcyjnych danych.
- Cache JSON zawiera metryki, score każdego przykładu i datę UTC. Klucz uwzględnia treści,
  etykiety, metadane modelu, wersje bibliotek i próg. Błędy i niezgodności korzystają
  z zapisanych predykcji; retrening lub zmiana danych unieważnia wynik. Błąd jednego modelu
  pozostawia wyniki pozostałych. Macierz i metryki liczone bez ciężkich importów sklearn.
- Surowe wyniki i przykłady: `data/cache/m5-benchmark.json`, rekordy w
  `data/cache/evaluation/`. Odtworzenie (z katalogu projektu, w aktywnym venv):

  ```powershell
  python scripts/download_imdb.py
  $env:OMP_NUM_THREADS="4"
  $env:MKL_NUM_THREADS="4"
  python -m opimon.sentiment.benchmark --train --download-transformer --fetch-live --max-test 1000
  ```

  Ponowienie bez flag train/download/fetch wykorzystuje lokalne dane i cache.
  Nowe pobranie live zmienia próbkę, więc wyniki mogą się różnić. Czas tabeli obejmuje
  predykcje, bez wczytania wag. Źródło API: https://partner.steamgames.com/doc/webapi/IUserReviewsService .
- Testy M5 (9): ręczne metryki, niepoprawne wyniki modeli, unieważnianie i uszkodzenie
  cache, zero etykiet, filtry źródeł, przykłady i niezgodności, odporność na błąd modelu,
  ponowne użycie predykcji przez fasadę. Dla X2: powyższa tabela i ograniczenia są wkładem O2.
- Końcowa poprawka O2: cache wyników korzysta z tego samego helpera synchronizacji JSON
  co IMDB; równoległe wywołania na Windows są objęte testem regresji. Cały zestaw po poprawce:
  133 zaliczone, 3 pominięte; Ruff czysty i Streamlit HTTP 200.
