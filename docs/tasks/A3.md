## Kryteria akceptacji
- [x] Filtry: obiekt, model, sentyment, zakres dat, pewność (score), słowo; ustawiane także przez `nav.open_reviews`
- [x] Szczegóły opinii po zaznaczeniu w tabeli: pełny tekst, metadane, predykcje WSZYSTKICH modeli, etykieta źródła, link
- [x] Podświetlenie szukanego słowa w tekście (i wyjaśnienia `explain`, jeśli model je ma)
- [x] Filtr „model się myli” (predykcja ≠ etykieta źródła)
- [x] Limit lub paginacja przy > 1000 opinii (GUI się nie zawiesza)
- [x] Testy GUI (zaznaczenie przez `session_state`) i testy filtrów bez GUI

## Notatki z realizacji
- Logika w `opimon/analytics/filters.py` (`ReviewQuery`, `apply_filters`, `paginate`,
  `highlight_html`, `is_misclassified`); widok `opimon/ui/reviews_view.py`, strona tylko go woła.
- **Filtry:** obiekt i model (przez `scored_reviews`), sentyment (w tym „bez predykcji”), fraza
  (bez rozróżniania wielkości liter, podciąg), daty „od / do” (dni UTC, włącznie), zakres
  P(pozytywny) – zawężenie wyklucza opinie bez predykcji, „model się myli”. „Wyczyść filtry”
  działa przez `on_click` (zmiana stanu widżetów przed ich utworzeniem).
- **`nav.open_reviews`** ustawia obiekt, sentyment, frazę, `review_id` oraz – nowe, wstecznie
  zgodne – `date_from` / `date_to` (wpis w dzienniku). Pozostałe filtry są wtedy zerowane.
  Dashboard przekazuje zakres dni klikniętego słupka trendu.
- **`review_id` (prośba O2/M7):** wskazana opinia jest pokazywana w szczegółach także wtedy,
  gdy nie spełnia filtrów (z adnotacją). Zaznaczenie wiersza w tabeli zmienia pokazywaną opinię.
- **Szczegóły:** tekst z podświetleniem frazy (żółte) i słów z `explain_text` wybranego modelu
  (zielone / czerwone, wyłączalne), metadane, etykieta źródła, przycisk do źródła (`url`),
  tabela predykcji wszystkich modeli: zapisana w bazie albo – dla gotowego modelu bez zapisu –
  policzona na żądanie (cache w `session_state`), z informacją o zgodności z etykietą.
  Tekst renderowany jako HTML z `html.escape` (bez wstrzykiwania znaczników z Internetu).
- **Paginacja:** 25 / 50 / 100 / 200 na stronę (domyślnie 50); numer strony przycinany do
  zakresu. Test z 1295 opiniami.
- Tabela predykcji nie ma `on_select`, więc AppTest nie widzi jej klucza; test wybiera ją jako
  tabelę różną od `rev_table`.
